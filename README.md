# An-lise-de-Sentimentos-em-Python
A ideia principal é extrair conhecimento de textos não estruturados, como publicações em redes sociais, e quantificar a opinião pública sobre um tema. como uma marca, evento esportivo ou figura pública. Essa análise é uma aplicação prática de BData e IA, mostrando como o Py pode lidar com grandes volumes de texto de forma eficiente.
